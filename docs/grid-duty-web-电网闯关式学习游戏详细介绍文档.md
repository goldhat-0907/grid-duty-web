## 五大特色系统

### ① 7 种角色，各有所长也各有所"盲"

不是换皮，而是真换"视角"：

- **值班员**操作快如闪电（耗时 ×0.8），却**看不到全网潮流**；
- **调度员**可下全网指令，但每道指令要等 3 秒**"调度回执"**才落地——真实电网的指令链延迟被原样搬进游戏；
- **虚拟电厂运营商**看得见资源池全景、聚合操作飞快，却**没有一次设备的操作权**——"聚合商动不了开关"，行业现状即游戏规则。

角色盲区被物理化呈现：面板直接隐藏、按钮直接置灰，"无操作权，请联系检修班"。你会在重玩中真正理解——**岗位上你只能看到你的岗位该看到的**。

### ② 11 项技能，"先学后用"的执业成长线

巡检记录法、倒闸操作权、并网操作证、保护定值整定、需求响应协调权、风功率预测、VPP 调度权、微电网并离网运行……技能逐关解锁，并与关卡动作**硬门禁联动**：没有"并网操作证"，储能放电顶峰按钮就是灰的。就像现实中的持证上岗——先学基础路径，再解锁进阶手段。

### ③ 三级提示系统：知识 / 技能 / 操作，随时可查但要"花时间"

- **知识提示**：工程原理 + 课程知识点 + 记忆口诀（"无功就地平衡——先补容性无功，再动分接头"）；
- **技能提示**：本关可用技能与未解锁技能预告；
- **操作提示**：状态感知教练，按当前表计状态给出递进指引并高亮设备，但**绝不替你操作**。

查阅提示会消耗宝贵的值班时间——**专家少看、新手保通关**，教学张力由此而生。

### ④ 进局前四步设置：身份 → 关卡 → 难度 → 辅助

- **难度三档**：新员（时长 ×1.3、提示免费）/ 标准 / 专家（时长 ×0.85、漂移加剧、红线收紧、学分 ×1.2）；
- **辅助三档**：引导（一对一教练全程在线，新手与课堂演示首选）/ 平衡 / 挑战（全靠真本事）。

新手保通关，老手走挑战，同一份数据包装下从入门到精通的完整曲线。

### ⑤ 高保真沉浸体验：一座会"呼吸"的值班室

- **深色 SCADA 值班台**：纯矢量绘制（SVG + CSS，零位图），指针微颤、数值滚动补间、通流线路流动发光；
- **Web Audio 合成音效**（零音频文件）：告警分级蜂鸣、调度回执对讲机"滴"、红线临近的心跳音与环境电流底噪；
- **角色人设**：换班动画、开场独白、值班中的事件吐槽气泡、结算时的角色点评（"交接班最忌漏项，这次多留了个心。"）；
- **心跳感**：倒计时最后 10 秒变红加速、红线边框低频脉冲、移动端触觉震动。

## 技术亮点：轻到极致，才能随处可玩

- **纯静态网页**：原生 HTML/CSS/JS（ES Modules），零构建步骤、零第三方运行依赖、零服务器——托管在 GitHub Pages 上，一个链接走天下；
- **数据驱动**：全部关卡数值来自结构化 JSON 数据包（`levels.js`），引擎不感知具体关卡——**改数据即改关卡**，天然支持课程内容扩展与二次开发；
- **引擎与体验分层**：通用表计引擎 + 模拟演化 + 体验增强层（enrichment）清晰解耦，11 关共用一套引擎代码，配自动化可行解测试与红线覆盖测试；
- **零资源文件**：音效全部由 Web Audio 实时合成，图形全部矢量绘制，加载体积小到可以忽略；
- **进度本地持久化**：关卡星级、技能、知识卡、角色解锁与个人设置全部存于浏览器，随玩随续。
